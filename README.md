## 🚀 Running the Application

- **Development Server:**
  ```bash
  npm run dev
  ```
  Runs Vite dev server on port `3000` (`http://0.0.0.0:3000`).

- **Production Build:**
  ```bash
  npm run build
  ```
  Generates optimized production bundle in `dist/`.

- **Type Check / Lint:**
  ```bash
  npm run lint
  ```
